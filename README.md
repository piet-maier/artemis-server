## Install [pipenv](https://pipenv.pypa.io/en/latest/)

```
pip install --user pipenv
```

## Install Packages

```
pipenv install -d
```

## Run [Flask](https://flask.palletsprojects.com/en/3.0.x/)

```
flask run
```

## Run [pytest](https://docs.pytest.org/en/8.0.x/) & [coverage](https://coverage.readthedocs.io/en/latest/)

```
coverage run -m pytest
```

```
coverage report
```
